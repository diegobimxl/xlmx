BIM Envelope Compliance Workflow

Assign ASHRAE 90.1 parameters as Revit shared parameters on wall, roof, and floor types: U_Value_Effective, R_Value_CI, Assembly_ASHRAE_Compliant. Use Revit Energy Settings to export gbXML with correct assembly U-values to EnergyPlus or eQUEST for whole-building compliance path (ASHRAE 90.1 Appendix G). For prescriptive path, these exact U-values must match the 90.1 tables. Continuous insulation (CI) U-values must be calculated separately from clear-field values using ASHRAE Handbook fundamentals metal-stud correction factors (20–45% reduction for metal framing).
