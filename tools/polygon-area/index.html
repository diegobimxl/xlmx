Polygon Area Calculator

Polygon Area Calculator

Enter polygon vertices as X/Y coordinates (or Easting/Northing). Uses the Shoelace (Gauss) formula. Add as many points as needed.

Coordinate Input

#X / EastingY / Northing

Formula Reference

Shoelace: A = |Σ(xᵢ·yᵢ₊₁ − xᵢ₊₁·yᵢ)| / 2 Perimeter: P = Σ √((xᵢ₊₁−xᵢ)² + (yᵢ₊₁−yᵢ)²) Note: closes automatically (last→first vertex)

Works for any simple (non-self-intersecting) polygon. Input in projected coordinates (UTM, local grid) for accurate metric/imperial results. Geographic decimal degrees give approximate results only.
