Tuning Effect Guide
Increase Kp (Proportional)
Faster response, reduces steady-state error. Too high → oscillation, instability.
Increase Ki (Integral)
Eliminates steady-state error. Too high → overshoot, integrator windup, slow recovery.
Increase Kd (Derivative)
Dampens overshoot, improves stability. Too high → amplifies noise, causes jitter.
Rule of thumb: start P-only
Add I to kill steady-state error. Add D only if overshoot is a problem. Avoid D on noisy signals.
