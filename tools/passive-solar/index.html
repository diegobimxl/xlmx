BIM / Design Integration Note

Model south-facing glazing in Revit with curtain wall system and set Analytical Surface properties: SHGC_South, U_Value_Whole_Window. Use sun path analysis in Revit or Insight 360 to validate overhang shading. Autodesk Insight can cross-reference passive solar gains against mechanical heating loads. For LEED v4 EAp2 (Energy Performance), passive solar contribution reduces heating EUI in the EnergyPlus energy model. Tag thermal mass walls as Assembly_Type = ThermalMass with Mass_Thickness_in and Mass_Density_pcf parameters for automated calcs.
