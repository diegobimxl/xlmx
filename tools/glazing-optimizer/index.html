BIM Glazing Optimization Workflow

In Revit, use Autodesk Insight sun path + solar analysis tools to validate SHGC and daylighting per facade. Set curtain wall type properties: WWR_Percent, SHGC_Orientation, U_Value_Whole_Window. For LEED IEQc8 (Daylight), simulate sDA 300/50% — higher WWR on N/S improves daylight while low SHGC on E/W controls glare. Use parametric mass models in Revit to test WWR variations before committing to curtain wall design. The ASHRAE 90.1 overall average SHGC approach (§5.5.4.3) allows trading higher SHGC on N for lower on S/E/W — model this in energy simulation.
