One-Time Pad Demo

Cryptography — OTP encryption demo with key generation and XOR visualization

CIPHERTEXT (hex)
DECODED BACK (verify)
A true OTP is unbreakable (Shannon, 1949) IF: key is truly random, at least as long as message, used only once, and kept secret. Any of these violated = insecure. This demo uses crypto.getRandomValues() for key generation.
