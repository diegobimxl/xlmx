BIM / CFD Integration

Model natural ventilation openings in Revit as Air Terminal or Generic Model families with parameters: Opening_Area_SF, Cd_Discharge_Coeff, NV_Strategy (Cross/Stack/SingleSided). For LEED EQc1 (Enhanced Ventilation), natural ventilation compliance requires multizone airflow model or CFD study. Autodesk Insight Wind Rose tool provides quick feasibility check. For detailed analysis, export Revit geometry to IES-VE MacroFlo or OpenFOAM for CFD simulation. Mixed-mode systems require BMS control sequences — coordinate with controls engineer and document in Revit MEP as control system families.
