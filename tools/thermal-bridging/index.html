BIM / ASHRAE 90.1 Documentation

ASHRAE 90.1 Table A3.2 provides adjustment factors (F_adj) for metal framing: 2x4 @ 16"oc = 0.50, 2x4 @ 24"oc = 0.60, 2x6 @ 16"oc = 0.55, 2x6 @ 24"oc = 0.65. Adjusted U = U_cavity × (1 - F_adj) + U_framing × F_adj. In Revit, assign R_Value_ClearField and R_Value_Effective as shared parameters on wall types. Use THERM 7 (free, LBNL) for detailed 2D thermal bridging PSI-value calculations at corners, jambs, and slab edges. Document ψ-values (linear thermal transmittance) for Passive House PHPP and LEED EAc1 energy models.
