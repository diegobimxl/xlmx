Algorithm Comparison

Fixed Window
+ Simple, low memory (O(1))
+ Easy to implement
− Burst at window edge (2× spike)
− Not smooth
Sliding Window
+ Smooth distribution
+ No edge burst problem
− More memory O(n requests)
− Slightly complex
Token Bucket
+ Allows controlled bursts
+ Flexible, widely used
− Bucket state per client
− Needs refill logic
Leaky Bucket
+ Perfectly smooth output
+ Protects downstream
− Ignores user experience
− Always adds latency
