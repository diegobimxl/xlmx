BIM / Hygrothermal Analysis Integration

This tool uses the simplified steady-state Glaser method (ISO 13788). For accurate hygrothermal analysis, use WUFI Pro or WUFI 2D with transient climate data. Model wall assembly layers in Revit with Vapor_Permeance_Perms and R_Value shared parameters on each layer within the compound wall type structure. Export Revit assembly data for WUFI input. ASHRAE 160 requires hygrothermal analysis for walls in Climate Zones 5+. For Passive House PHIUS certification, interior surface temperature must stay above dew point (verified via THERM 2D linear thermal bridging analysis at all connections).
